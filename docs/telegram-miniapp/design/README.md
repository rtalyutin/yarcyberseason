# Дизайн Telegram Mini App — решение шага 3

## Сохранённое

- Два экрана: главная и один турнир `dota2-autumn-2026`.
- Настоящие логотип ЯКС, карта, «Разлом» и три существующих партнёра.
- Реальное состояние данных: регистрация закрыта, 16 участников, матчи и Swiss-таблица ещё не опубликованы.
- Editorial esports-язык сайта: тёмное поле, тонкие технические линии, плотная типографика, красный/cyan как сигналы; без градиентов.

## Варианты

### A — «Разлом» (рекомендуется)

Главная продолжает утверждённый образ Dota HOME, но сворачивает его в вертикальную афишу. Турнирная часть становится спокойнее: красный работает только как статус/активный раздел, данные лежат в строгих строках. Этот вариант сильнее связывает miniapp с основным сайтом.

### B — «Турнирная сетка»

Главная сразу выглядит как приборная панель турнира: дата, 16/16 и формат доступны без прокрутки. Кобальт и cyan дают более нейтральный esports-язык, но эмоциональная связь с «Разломом» слабее.

## Правила переноса в рабочий интерфейс

- Контентный контейнер — до 768 CSS px; ключевой макет — 390 px, проверки — 360/390/430/768 px.
- Safe-area берётся из CSS-переменных RuntimePort; минимум касания — 44 px.
- Навигация разделов прокручивается внутри себя, но не создаёт горизонтальный скролл страницы.
- Сетку плей-офф прокручивать внутри выделенного контейнера; не ужимать до нечитаемой картинки.
- Логотипы команд не являются ссылками. При ошибке используется `/assets/teams/_default.svg`.
- Loading, empty и error — разные состояния. Пустой слот не получает `0:0`.
- Focus-visible: контрастная двухпиксельная рамка; при `prefers-reduced-motion` переходы отключаются.

Исходники макетов: `design-options.html` и `design-options.svg`; общие токены: `src/telegram/design/tokens.css`. `design-options.png` экспортирован из SVG и служит для выбора направления, а не доказательством работающего UI.
