# Telegram desktop: отображение и закрытие — 16.09.2026

Пользователь сообщил о слишком узкой колонке на desktop и неудобном закрытии Mini App.
Исправление подготовлено; публикация и фактическая проверка новой версии в Telegram Desktop ещё не выполнены.

## Изменение

- В рабочую ветку сохранно объединён main `301127ca09a1d4aabef1bebfaee537db773b9ca4`, включая новые данные, ростер и логотип Пивной Кеги.
- До 960 CSS px сохранена мобильная основа; от 960 px — две колонки главной/турнира, контейнер до 1440 px, более крупная типографика. Участники от 1200 px располагаются в две колонки, в исходном порядке.
- Шапка закреплена при прокрутке и использует текущий верхний safe-area. Close отделён от Back: `WebApp.close()` против перехода на главную miniapp.
- В Telegram доступна клавиша Esc, кроме занятых событием/редактированием случаев; слушатель снимается при disposal. В обычном браузере действие «На сайт» переводит на `/`, не пытаясь закрыть чужую вкладку.
- Общая шапка и живой RuntimePort сохраняют закрытие при загрузке/ошибке данных и render fallback. До создания runtime/bootstrap SDK доступны штатные controls Telegram.
- Только «Разлом» и русский; остальные разделы шага 6 не реализовывались этим исправлением.

## Фактическая проверка

- Production build — PASS; 50 команд и 120 матчей валидированы.
- После build: `node --test tests/*.test.mjs` — **109/109 PASS**. Первый запуск набора до готовности build дал 108/109: packaging test ожидал ещё не созданный `dist/client/index.html`; последовательный прогон после сборки прошёл. Это ошибка порядка проверки, не изменение приложения.
- Независимый verifier `/root/verify_desktop_close`: проверены фактические runtime/JSX обработчики, различие close/back, Esc и cleanup, header без модели, доступные имена/44px controls и сохранность основного сайта. Найденный пробел loading/error исправлен и повторно проверен. Подтверждённых дефектов исходников этого исправления не осталось.
- Расчёт геометрии CSS при нулевых safe-area: ширина приложения для окон 320/390/768/960/1440/1920/3200 равна 320/390/768/896/1376/1440/1440 px. Это расчёт исходного CSS, не измерение браузерного рендера.
- Визуальный просмотр новой сборки: **NOT_VERIFIED**. Cloud browser отказал localhost (`ERR_BLOCKED_BY_CLIENT`) и локальному file URL (URL policy). Обход не выполнялся, альтернативный браузер не использовался. Локальный React-стенд был собран, но не открыт.
- Новое фактическое закрытие окна в Telegram Desktop: **NOT_VERIFIED**. Тесты подтверждают вызов host bridge, не факт закрытия пользовательского клиента.
- Приёмка шага 5 от Романа 16.09 сохраняется для предыдущей опубликованной сборки; не перенесена на новую версию автоматически. После публикации проверить широкое окно, обе страницы, прокрутку списка, Close и Esc на desktop, коротко сверить мобильный экран.
