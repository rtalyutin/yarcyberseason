## L0 → L1/L2/L3 → L6

- L0: форма `NormalizedMap` описана и проверяется перед рендером. Нормализованный результат остаётся единственным источником счёта и карт.
- L2: поддержано опубликованное поле `broadcastUrl` как вариант `streamUrl`, одинаковые ссылки не дублируются. HTTPS без credentials; неподходящие ссылки не становятся действиями. Публичные JSON и общий normalizer не изменены.
- L1/L3: `MatchesSection`/`MatchRow` показывают этап, BO, команды, исходный статус, известную дату и подтверждённый счёт. Native `details/summary` раскрывает опубликованные карты, примечание и материалы матча. Отдельной страницы матча и дополнительных маршрутов нет.
- Подтверждённый технический исход подписан отдельно, карты не изображаются сыгранными. Неподтверждённые completed/walkover/bye ожидают подтверждения. Счёт серии не пересчитывается из статистики карт. Отсутствующий счёт/карты имеют отдельное пустое состояние.
- Расписание и Матчи используют общий `matchStatusLabel`. Логика закрытия, Telegram bridge, router и предпочтения сохранены. RuntimePort передан из MiniAppView в раздел; ссылки срабатывают только по нажатию.
- Меню показывает пять реализованных разделов: О турнире, Участники, Формат, Расписание, Матчи. Swiss/Плей-офф/Итоги ещё не объявляются готовыми.
- Метаморф: продолжен принятый «Разлом» — тёмные панели, ivory-счёт, cyan-дата и раскрытие, тонкие границы. Без новой графики. CSS ограничен tg-классами, содержимое переносится, summary получает видимый keyboard focus. Сохранены широкая компоновка, sticky header и отдельное закрытие. Это описание реализации; визуальная приёмка заблокирована.
