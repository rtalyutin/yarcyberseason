## L0 → L1/L3 → L6

- L0 не меняется: RulesSection принимает `stages[].rules/notice`, `registration.message`, `rewards.referralContest`; ScheduleSection — `timeline[]` и единый `matches[]` из L2. Raw JSON и отдельные результаты внутрь renderers не передаются.
- Правила, названия этапов, условия конкурса и строки timeline приходят из опубликованного источника. Данные и регистрация не изменяются. Полный юридический регламент/PDF этим срезом не заявляется реализованным.
- Расписание сохраняет порядок источника и показывает все нормализованные матчи, в том числе без точной даты. `dateDisplay` вычислен L2: известный offset → МСК; дата без времени → без полуночи; время без пояса → явная оговорка. Наступившая дата не изменяет статус. Подробности карт и отображение итогового счёта относятся к следующему срезу «Матчи».
- В navigation добавлены только готовые `rules` и `schedule`; оставшиеся разделы при прямом входе по-прежнему честно обозначены как готовящиеся. Смена разделов использует уже проверенный router replaceState; нового маршрута нет.
- Метаморф: осмотрен реальный исторический `step4-preview.jpg`, прочитаны дизайн и desktop-правила. Сохранены тёмное поле, ivory-типографика, красный активный раздел и cyan-даты. Формат использует смысловые пары label/value; timeline — последовательность исходных вех. Новых изображений/тем нет. CSS ограничен tg-классами, nav имеет min-width:0 для внутреннего скролла. Это замысел и реализация, не свежая визуальная приёмка.
