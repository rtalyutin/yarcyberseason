# WebMCP: публичные данные ЯКС

Страница `/webmcp` предоставляет шесть инструментов только для чтения.
Используются `src/data/tournaments/index.js` и `src/data/community.js` — те же
турниры и модель команд/матчей, что на основных страницах сайта. Обработчики
не обращаются к GitHub, не записывают файлы, браузерное хранилище или серверные
данные и не меняют страницу. Исходные JSON остаются источником истины.

## Инструменты

| Инструмент | Параметры | Содержание |
| --- | --- | --- |
| `ycs_list_tournaments` | `query`, `discipline`, `status`, `offset`, `limit` | Список турниров |
| `ycs_get_tournament` | обязательный `tournamentId` | Описание, даты, правила, регистрация, призы, таблицы, этапы, участники и итоги |
| `ycs_list_matches` | `tournamentId`, `teamId`, `discipline`, `status`, `query`, `offset`, `limit` | Опубликованные матчи, счёт и карты |
| `ycs_get_match` | обязательные `tournamentId`, `matchId` | Один матч, примечания, источник и связи сетки |
| `ycs_list_teams` | `query`, `tournamentId`, `discipline`, `offset`, `limit` | Канонический реестр команд, поиск по прежним названиям |
| `ycs_get_team` | обязательный `teamId` | История участия, места и статистика отдельно по дисциплинам |

В списках все параметры необязательны. `discipline`: `Dota 2` или
`Counter-Strike 2`. `tournamentId` принимает ID либо slug; `teamId` также
принимает исторические ID из реестра. Поиск регистронезависим и нормализует
Unicode NFKC. `query` в матчах учитывает прежние названия обеих команд.

Успех: `{ ok: true, dataVersion, ... }`. Деталь возвращается в поле
`tournament`, `match` или `team`. Список содержит `items`, `total`, `offset`,
`limit`, `nextOffset`; `null` в `nextOffset` завершает обход. Размер страницы
по умолчанию 50, максимум 100. Пустой корректный запрос даёт пустой список;
неизвестный обязательный объект или объект фильтра — `NOT_FOUND`.
Некорректные и лишние параметры — `{ ok: false, dataVersion,
error: { code: 'INVALID_ARGUMENT', message } }`. Браузер может отвергнуть
несоответствующий JSON Schema запрос ещё до вызова обработчика.

## Смысл данных

- `dataVersion` — SHA-256 исходных JSON, списка импортируемых турниров и
  общей модели интерпретации. Вычисляется Vite для этой сборки. Новый `main`
  не меняет ответы уже опубликованной сборки; для получения новой версии
  нужна публикация и загрузка её страницы.
- `linkedTeamCount` — число команд с установленной связью в реестре. Это
  не заявка на полный охват исторического турнира. Его исходные таблицы и
  опубликованные факты доступны в `ycs_get_tournament`.
- В этапах турниров `matchKeys` ссылаются на опубликованные матчи.
  Для деталей/пагинации используйте инструменты матчей; идентификатор матча
  уникален только внутри своего турнира.
- `result.score` / `result.series` — подтверждённый нормализованный счёт.
  `result.sourceScore` может содержать неподтверждённый исходный счёт;
  проверяйте `result.confirmed`, `result.known`, `resultIssue` и `note`.
- `result.technical` отделяет технический исход от сыгранной серии.
  Статистика использует существующий `teamSummary`; технические решения
  не добавляются к спортивным победам/поражениям.
- Пустые слоты сетки и записи `published: false` не выдаются как матчи.
  Отсутствующие даты, годы, карты и составы игроков не восстанавливаются
  догадками. `maps: []` означает отсутствие опубликованных карт.
- Ответы содержат отделённые копии данных: изменение ответа потребителем
  не изменяет модель сайта. Ссылки относительны текущему origin.

## Браузер

Инструменты регистрируются через `document.modelContext.registerTool` в
основной странице. `AbortSignal` снимает регистрацию при размонтировании;
асинхронная регистрация сериализована для React StrictMode. При отсутствии
API страница остаётся доступной и показывает отсутствие поддержки.
Страница должна оставаться открытой. Регистрация внутри iframe не нужна.

Официальные источники, проверены 13 сентября 2026:
- [OpenAI Site tools](https://learn.chatgpt.com/docs/webmcp)
- [WebMCP: API и AbortSignal регистрации](https://webmachinelearning.github.io/webmcp/)

## Проверка

```sh
npm ci
npm run test:webmcp
npm run test:tournament
npm run test:community
npm run test:matchday
npm run build
npm run test:sites
npm run preview -- --host 127.0.0.1 --port 4173
```

Открыть `/webmcp` во встроенном браузере клиента, дождаться статуса шести
инструментов и проверить реальное обнаружение Site tools. Пример сквозного
сценария: найти PIVNAYA KEGA, получить её историю, выбрать турнир CS2 и
получить гранд-финал. Ожидается исходный порядок bobr1ki/PIVNAYA KEGA,
счёт серии 2:3, пустые карты и опубликованное примечание. Отдельно проверить
Qual без года и autumn с 16 участниками и нулём опубликованных матчей.

Сборка и локальная проверка не выполняют push, merge или публикацию сайта.
